# Futbol Fitness Website

Promotional site for **Futbol Fitness** — bold, soccer-inspired high-intensity training sessions.

**Live site (after GitHub Pages is enabled):**  
https://futbolfitness.github.io/website/

## Quick start

1. Open `index.html` or visit the GitHub Pages URL above.
2. To update upcoming sessions → edit the `SESSIONS` array at the bottom of `index.html`.
3. To receive registrations in a private Google Sheet → follow **SETUP.md**.

## Enable GitHub Pages

1. Go to **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / root
4. Save

Your site will be live at: `https://futbolfitness.github.io/website/`

## Files

| File | Purpose |
|------|---------|
| `index.html` | Complete single-file website |
| `SETUP.md` | Google Sheets + Apps Script backend instructions |
| `logo-*.jpg/png`, `banner.jpg` | Branding images |

## Owner features

- Registration form posts to Google Sheets (once configured)
- Password-protected "Owner login" in the footer links to your private sheet
